# Set Microsoft Foundry Speech API key

Set Microsoft Foundry Speech API key

## Usage

``` r
foundry_set_speech_key(key)
```

## Arguments

- key:

  Character. Speech resource API key.

## Value

Invisibly returns `TRUE` if the key was set successfully.

## Examples

``` r
if (FALSE) { # \dontrun{
foundry_set_speech_key("your-speech-key")
} # }
```
